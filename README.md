## About Me

Software developer focused on building business systems that connect operations, finance, data and internal workflows. My repositories show production-oriented work across fullstack web platforms, desktop administrative systems, mobile applications, data integrations, reporting tools and modular backend services.

I work mainly with TypeScript, Node.js, React, C#, PHP and Kotlin, using relational databases, API-driven architectures, document generation, Excel/CSV processing, authentication, dashboards, geolocation and automation scripts.

## Featured Projects

### servicio_prestaciones

Modular lending and contract management platform built as a TypeScript monorepo.

- Solves: contract creation, customer management, payments, capital payments, extensions, file evidence and cash operations.
- Stack: React, TypeScript, Vite, Ant Design, Node.js, Express, MariaDB, npm workspaces.
- Architecture: API Gateway plus independent services for auth, customers, contracts, payments, files and cash.
- Business impact: separates core financial workflows into maintainable services and shared packages for config, database access, logging, validation and types.

### sigae

Fullstack operational platform with a React client and TypeScript backend.

- Solves: internal management workflows with dashboards, documents, uploads, real-time communication and business data processing.
- Stack: React 19, Vite, TypeScript, Express 5, Socket.IO, JWT, bcrypt, Axios, Tailwind CSS, Ant Design.
- Data: MySQL, SQL Server and MongoDB dependencies are present in the backend.
- Reporting: Excel, CSV, PDF, charts, Power BI client integration and document/image processing.
- Integrations: OpenAI SDK, Socket.IO, file uploads and scheduled jobs with node-cron.

### compra_venta

Desktop administrative and financial system for purchase, sales, contracts and cash workflows.

- Solves: customers, contracts, receipts, inventory, merchandise, cash movements, expenses, accounting summaries and reporting.
- Stack: C#, .NET Framework 4.7.2, Windows Forms, MySqlConnector, SQL scripts.
- Architecture: service layer, model layer and WinForms views organized by business domain.
- Business impact: centralizes operational control for purchase/sale processes, contract history, financial reports, backup, authentication and updates.

### movilidadD / DSC

Web backend and operational tooling for field and portfolio management workflows.

- Solves: data loading, portfolio assignment, file processing, progress tracking and operational forms.
- Stack: PHP 8.2+, MySQLi, Composer, PhpSpreadsheet, SimpleXLSX, Dotenv, JavaScript, SCSS.
- Infrastructure: Docker Compose with Nginx and PHP-FPM.
- Data: SQL migrations, schema files and Excel templates for operational processing.

### MovilidadApp

Android application connected to operational workflows.

- Solves: mobile data capture and field-oriented processes with local persistence and API communication.
- Stack: Kotlin, Android, Jetpack Compose, Material 3, Hilt, Room, Retrofit, Gson, DataStore.
- Capabilities: location services, charts, local database layer and release signing configuration.

### interventoria

Desktop application for operational review and file-based workflows.

- Solves: interventoria workflows with a desktop interface and Excel handling.
- Stack: React, Electron, Ant Design, Axios, XLSX, dotenv.
- Packaging: electron-builder with Windows NSIS targets for x64 and ia32.

### IntegracionAcess

Data integration workspace with Power BI reports, SQL and Node.js scripts.

- Solves: structured data extraction and report preparation for operational and financial analysis.
- Stack: Node.js, csv-parser, mysql2, SQL, Power BI `.pbix` assets and Excel files.
- Business impact: supports data movement from CSV/SQL sources into reporting workflows.
