## About Me

Desarrollador de software enfocado en sistemas empresariales, backend, aplicaciones internas, automatización de datos y soluciones operativas. Trabajo con arquitecturas modulares, clientes web modernos, aplicaciones de escritorio, aplicaciones Android, procesamiento de archivos, dashboards y flujos conectados a bases de datos.

Mi trabajo técnico combina desarrollo fullstack, servicios backend, interfaces administrativas, reportes, autenticación, carga y transformación de datos, generación de documentos, integración con sistemas de información y herramientas para operación diaria.
